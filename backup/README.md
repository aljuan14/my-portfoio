# Alfito Juanda - Portfolio

A modern, responsive, single-page developer portfolio built to showcase projects, skills, and professional experience. The design features a unique Neo-Brutalism light-mode aesthetic, emphasizing bold typography, high-contrast layouts, and interactive elements.

## Features

- Custom Neo-Brutalism Design: Distinctive layout with sharp borders, abstract geometric shapes, and stark shadows.
- Responsive Layout: Fully optimized for both mobile and desktop environments.
- Bilingual Support: Built-in, lightweight JavaScript toggle for switching between English and Indonesian languages without page reloads.
- Dynamic Elements: Incorporates a continuous scrolling technology ticker and interactive hover states for project cards.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- Google Fonts (Syne for headings, DM Sans for body)
- Vanilla JavaScript (for language translation logic)

## Featured Projects

This portfolio highlights several key projects:

- MediSync: AI Hospital Orchestration system featuring automated triage and clinical diagnosis suggestions.
- Jivara: AI Medication Interaction Monitor utilizing computer vision to prevent dangerous food and drug contraindications.
- Warung Tante: Integrated POS & HRIS system with geolocation-based attendance tracking.
- ID Ethnicity: Deep learning research achieving high accuracy on facial feature classification using FaceNet and SVM.
- Additional applications involving AI Agents, MobileNetV2 classification, and Machine Learning text classification.

## Local Setup

Since this is a static single-page application without any complex build steps, you can view the portfolio by simply opening the index.html file in any modern web browser.

1. Clone the repository:
   git clone https://github.com/aljuan14/my-portfoio.git

2. Navigate to the project directory:
   cd my-portfoio

3. Open index.html in your preferred browser.
