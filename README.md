# Alfito Juanda - Portfolio

This is the source code for my interactive web portfolio. I am an AI & Fullstack Web Engineer focusing on data-driven solutions, machine learning, and modern web applications.

## Overview

Built with Svelte, this portfolio showcases my professional experience, projects, and skills in AI and Fullstack development. The interface emphasizes a clean design and optimal performance.

## Development

Install dependencies using `bun`, then start the development server:

```sh
bun install
bun run dev --open
```

## Production Build

To create an optimized production build:

```sh
bun run build
```

Preview the build locally:

```sh
bun run preview
```
